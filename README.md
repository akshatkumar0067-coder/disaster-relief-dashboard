# Disaster Relief Fund & Transparency Dashboard

**ReliefConnect** is a web dashboard that shows how disaster relief funds are collected and used, so donors can see where their money goes.

## Features

- Campaign overview and live updates
- Fund transparency dashboard
- Social sharing buttons (Twitter, Facebook, Copy Link)
- Responsive layout for mobile and desktop
- Font Awesome icons

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome 6.4.0 (CDN)

## Project Structure

```
Disaster.html/
├── disasterfund.html   # Main page
├── assesment2.css      # Styles
└── assesment2.js       # Scripts
```

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/akshatkumar0067/disaster-relief-dashboard.git
   ```
2. Open the project folder.
3. Open `Disaster.html/disasterfund.html` in your browser (or use the VS Code **Live Server** extension).
